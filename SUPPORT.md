# Getting help

*Vous pouvez écrire en français ou en anglais.*

- **Questions, ideas, “how do I…?”** — ask in [Discussions](https://github.com/orgs/parler-haut-interagir-librement/discussions). Someone may
  have asked before: search first.
- **A bug** — open an issue in the repository concerned with the **Bug report** form. A minimal example that
  reproduces it helps more than anything else.
- **A missing feature** — open an issue with the **Feature request** form, starting from the problem you want solved.
- **A security problem** — never in public: follow [SECURITY.md](SECURITY.md).
- **Documentation** — each package has a README and a `doc/` folder; [ph-il.ca](https://ph-il.ca) will gather them in one catalogue.

## What to expect

PHIL is maintained by a small team, on a best-effort basis: there is no guaranteed response time and no paid
support. Most packages are still in incubation (see the [organisation profile](https://github.com/parler-haut-interagir-librement)); until a
package is released, its behaviour and its API may change.

Please follow the [code of conduct](CODE_OF_CONDUCT.md) in every exchange.
